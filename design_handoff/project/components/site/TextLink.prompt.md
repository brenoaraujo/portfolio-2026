The portfolio's call to action — there are no buttons anywhere in the source, only this underlined link with an arrow.

```jsx
<TextLink href="mailto:hi@example.com">Let's talk</TextLink>
<TextLink href="#" style={{alignSelf:"flex-end"}}>See full details on Linkedin</TextLink>
```

Set `arrow={false}` for an in-page link. Color is `var(--text-link)` (rgb(100,99,96)), never black.

Intentional addition — no Figma symbol; promoted from the repeated underlined-link + arrow pattern.
