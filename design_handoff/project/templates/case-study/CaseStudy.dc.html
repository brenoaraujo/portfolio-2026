User Flow and UI · 2024-2025

Onboarding for a new revenue streamline, cut from eleven screens to four.

The team had a working funnel and no idea where it leaked. I rebuilt the flow around the two decisions a new seller actually makes, then prototyped it in code so we could argue with something real instead of with each other.

Where it leaked

Sixty-one percent of sign-ups stopped on the payout step. Not because it was hard — because it arrived before anyone had a reason to trust us with a bank account. We were asking for the riskiest thing first.

So we moved the money question to the end, and let people see one real earnings number before we asked for anything.

That reorder is the whole case study. Everything after it is craft: fewer fields, plainer labels, a progress model that tells the truth about what is left.
