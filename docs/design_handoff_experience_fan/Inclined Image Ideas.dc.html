Turn 3 — targets that never move

The preview goes where the cursor isn't.

The loop in 2a was structural: the thing you hover was also the thing that moved. In both of these the small frames hold one fixed position for the whole interaction — the large image opens in the empty space beside them, so the pointer never lands on a new target and nothing can re-trigger.

Turn 2 — 1d, with a preview that never moves the page

Two hovers, one of them free.

Hover a row and the tilted stack fades into the empty third column, exactly as in 1d. Hover one frame in that stack and it lifts to full size on top of the page — a transform, not a layout change, so no row ever shifts under the pointer. While one is up, only the next frame stays visible at its right edge — a 48px target to step through the set one at a time. Leaving the row puts everything back.
